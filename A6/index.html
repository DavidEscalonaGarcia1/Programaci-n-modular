Neteja i validació de dades d’un formulari

Treballaràs amb text “brut” i hauràs d’aplicar tractament de cadenes i regex molt bàsiques (mòdul re) per normalitzar camps i detectar errors.

Enunciat

Què has de construir

Temps estimat: 60–90 min

Tens una llista de línies de text. Cada línia representa un registre amb aquest format aproximat: nom ; email ; telefon ; codi_postal ; comentari (però ve amb espais raros, majúscules, símbols, etc.).

1) Normalització (strings)

Nom
  • Eliminar espais extra (múltiples → un).
  • Format “Títol” (capitalitzar cada paraula).
  • Mantenir guions (ex: Maria-José).
Email
  • Passar a minúscules i fer strip().
  • Validar format bàsic amb regex.
Telèfon (Espanya)
  • Normalitzar a +34XXXXXXXXX (9 dígits).
  • Acceptar: 612345678, +34 612-34-56-78, 0034 611 22 33 44…
  • Si no es pot → invàlid.
Codi postal
  • Ha de ser exactament 5 dígits: ^\d{5}$.
  • (Extra) rebutjar 00000 o validar rang.

2) Neteja de comentari (regex)

  • Treure espais extra al principi/final i entre paraules.
  • Reduir !!! i ??? a un sol signe amb re.sub: Holaaa!!! → Holaaa!
  • (Opcional) treure caràcters raros finals.

3) Validacions (regex bàsiques)

Implementa funcions que retornin True/False: email_valid(), cp_valid(), telefon_valid().

Exemples d’entrada

"  Ana   López ; ANA.LOPEZ@gmail.com  ; +34  612-34-56-78 ; 08001 ;  Hola!! Vull info  "
"pepe perez; pepe_perez@correu.es; 612345678;28013;   m'encanta Python!!!   "
"MARÍA-josé ; maria.jose@correu ; 0034 611 22 33 44 ;  41001 ; Bones, truca'm."
"Juan; juan@gmail.com ; 123 ; 99999 ; ???"

Sortida esperada (format lliure)

Registre 1: OK
Nom: Ana López
Email: ana.lopez@gmail.com
Tel: +34612345678
CP: 08001
Comentari: Hola! Vull info
---
Registre 3: ERRORS -> email, telefon
Requisits

Checklist

Obligatori
  • Fer servir strip(), lower(), split() i ' '.join(...).
  • Fer servir re amb almenys re.fullmatch (o re.search) i re.sub.
  • Crear com a mínim 4 funcions (p.ex. una per camp).
  • Mostrar per pantalla OK o llista d’errors per registre.
Pistes regex (molt bàsiques)
  • Email simple: ^[\w\.-]+@[\w\.-]+\.\w{2,}$
  • CP 5 dígits: ^\d{5}$
  • Tel normalitzat: ^\+34\d{9}$
  • Reduir signes: r'!{2,}' → ! i r'\?{2,}' → ?
